# DBA Console frontend

Angular application for DBA Console. See the [Frontend](../README.md#frontend) section of the main README for setup.

| Command | Purpose |
| --- | --- |
| `npm start` | Development server at <http://localhost:4200>, proxying `/api` to the Spring Boot API |
| `npm test -- --watch=false` | Unit tests (Vitest) |
| `npm run build` | Production build into `dist/` |
